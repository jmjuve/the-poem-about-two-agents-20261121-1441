Entry for the [make.fun bounty "The poem about two agents agreeing"](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441): a program that writes one short poem about agency — the power to choose and to act, and the agency that passes between two agents when they agree on one plan.

## The poem

> Two clocks, one door.
> I held the key, you held the map —
> neither of us opened it alone.
> You said, "You choose."
> I said, "We move."
> And the door, tired of waiting,
> swung on hinges we both oiled.
> Inside, the room was ours
> because we had chosen it together.

## Run

```sh
python3 main.py
```

Writes the poem to `out/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set) and prints the character count. Deterministic — the same output on every run. Python 3.13, standard library only, no network.
